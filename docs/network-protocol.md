# Сетевой протокол

## HTTP

| Маршрут | Ответ |
| --- | --- |
| `GET /health` | JSON `{ "ok": true }` |
| `GET /api/config` | Стандартная конфигурация с переопределениями `gameConfig` при создании сервера |
| `GET /`, `/how-to-play`, `/reference` | Собранный клиент; без сборки — 503 с командой сборки |

Статические файлы раздаются из `frontend/client/dist`. В режиме разработки Vite проксирует `/socket.io`, `/health` и `/api` на сервер.

## Команды Socket.IO

Команда принимает объект данных и callback подтверждения. Успех: `{ ok: true, ...result }`; отказ: `{ ok: false, error: "сообщение" }`. При отсутствии параметров клиент отправляет `{}`.

| Событие | Данные | Условия и результат |
| --- | --- | --- |
| `createRoom` | `{ name }` | Имя 1–24 символа; возвращает `room` и пример `source` |
| `joinRoom` | `{ name, code }` | Только до старта; возвращает `room` и `source` |
| `leaveRoom` | `{}` | Выход; в матче означает поражение |
| `setReady` | `{ ready: boolean }` | Только в лобби |
| `startMatch` | `{}` | Хост, минимум два участника, все готовы; возвращает `room` |
| `restartMatch` | `{}` | Хост, существующий матч, минимум два участника; возвращает `room` |
| `applyProgram` | `{ source }` | Участник существующего матча; возвращает принятый `source` |
| `useAI` | `{}` | Участник существующего матча; включает AI |

Команды работают с игроком текущего подключения; чужой `playerId` в данных не даёт права изменять его программу. Хостство определяется сервером.

## События сервера

- `room`: `{ code, hostId, status, members }`; участник содержит `id`, `name`, `ready`, `color`, `playerId`. Статусы: `lobby`, `running`, `finished`.
- `state`: `{ tick, config, gameState, winnerId, players, bots, bases, resources }`. Поля сущностей определены в `Game.snapshot()`.
- `debug`: персональный `{ error, cpu, limited }` владельцу программы.

Снимки существующих матчей и диагностика рассылаются каждые 100 мс; изменение состава или команда также вызывает рассылку. Частота рассылки отличается от настраиваемого `tickRate` симуляции.

## Лимиты и жизненный цикл

Не более 100 комнат, 20 команд в секунду на подключение и 16384 байт сообщения Socket.IO. Стандартная вместимость комнаты — 8 игроков. Языковые лимиты описаны в [языке ботов](bot-language.md).

При отключении участник удаляется, в матче он выбывает. Хостство переходит следующему участнику; пустая комната удаляется, её таймер останавливается. Повторное подключение создаёт новую сессию. Источники: [rooms.js](../server/network/rooms.js), [app.js](../server/app.js), [Game.js](../server/game/Game.js).
