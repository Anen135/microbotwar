# Microbots Arena v1.0.0

Дата подготовки: 6 октября 2026 года. Первый выпуск MVP для настольных браузеров и небольших игровых комнат.

## Возможности

- Многопользовательские комнаты до восьми игроков: код приглашения, готовность и права хоста.
- Серверная симуляция движения, ресурсов, создания ботов, боя и победы.
- Встроенный AI и программирование армии через ограниченный DSL.
- Редактор с подсветкой синтаксиса, бюджетом исполнения и переходом к строке ошибки.
- Перезапуск с сохранением программ и режима управления.
- Матовый графитовый интерфейс с золотым акцентом, металлическими деталями и переключаемым ЭЛТ-фильтром.
- Отдельные страницы руководства и справочника; переходы сохраняют сессию и черновик.
- Документация проекта и отдельные инструкции для ИИ-агентов в `docs/`.

## Запуск готового архива

Распакуйте `microbots-arena-v1.0.0.zip` и откройте терминал в папке проекта:

```powershell
npm --prefix server ci --omit=dev
npm --prefix server start
```

Откройте `http://127.0.0.1:3001`. Клиент уже собран и включён в архив; установка зависимостей frontend для этого запуска не требуется. Исходники также включены. Инструкция по разработке: [getting-started.md](../getting-started.md).

Перед распаковкой можно сверить SHA-256 архива с приложенным `SHA256SUMS.txt` командой `Get-FileHash -Algorithm SHA256`.

## Ограничения

Матчи и комнаты хранятся в памяти и теряются при остановке сервера. Потеря соединения считается поражением; возвращение в начавшийся матч не поддерживается. Аккаунты, БД и мобильная версия отсутствуют. Публичная нагрузка и отдельный хостинг приложения не проверялись.

Публикация пакета на GitHub не запускает игровой сервер: пользователи запускают приложение самостоятельно.
