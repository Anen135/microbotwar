# Microbots Arena v2.0.0

Microbots Arena 2.0 меняет основу игры: игроки проектируют и запускают собственные взаимодействующие программы для микроботов.

## Что нового

- Боты исполняют только пользовательские программы; без программы бот бездействует.
- Игрок может создавать несколько программ и выбирать программу и конструкцию для новых ботов.
- `scan()` показывает только объекты в радиусе обзора. У каждого бота есть собственная память между тиками.
- Боты добывают металл, энергию и кремний в груз и разгружают его у своей базы.
- У конструкций есть скорость, броня, атака, обзор, груз, связь, CPU и энергия в рамках бюджета очков.
- Боты могут обмениваться сообщениями в ограниченном радиусе связи. Автоматической пересылки сообщений нет.
- Base Controller позволяет игроку программировать производство, видит собственные запасы и ботов, а также полученные сообщения.
- Сервер фильтрует состояние матча по видимости игрока и хранит только последнее известное положение скрывшихся объектов.

## Совместимость

Обновление меняет игровой цикл и API программ, поэтому прежние скрипты требуют адаптации. Ознакомьтесь с руководством [«Программируемые агенты»](../programmable-agents.md) и замените автоматические реакции явным кодом для сенсоров, добычи, доставки, сообщений и производства.

## Установка и запуск

Релизный архив содержит исходники и собранный клиент. Для запуска сервера из корня распакованного архива выполните:

```powershell
npm --prefix server ci --omit=dev
npm --prefix server start
```

Откройте `http://127.0.0.1:3001`. Активные комнаты хранятся в памяти сервера.

После добавления этой записи те же проверки запускаются повторно на итоговом commit, который будет отмечен тегом `v2.0.0`.
