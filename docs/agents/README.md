# Документы для ИИ-агентов

## Порядок чтения

1. Прочитайте корневой [AGENTS.md](../../AGENTS.md): он сохранён по требованию пользователя и описывает ранний scaffold.
2. Используйте [актуальное руководство](contributor-guide.md) для команд, соглашений и правил обновления документов.
3. Прочитайте [передачу проекта](handoff.md) и [обзор MVP](../overview.md).
4. При подготовке выпуска сверяйтесь с [release.md](../release.md).

## Передача работы

Записывайте выполненные изменения, проверенные команды, ограничения и конкретные оставшиеся задачи. Указывайте файлы и критерии завершения; отличайте прошлые результаты от текущего прогона.

Подтверждённые задачи, требующие более сложного анализа, выносите в отдельный файл этой папки и ссылайтесь на него из передачи. Файл не создаётся для предположительных задач. Незавершённые действия по выпуску перечислены в общем чек-листе релиза.

## Экономия токенов и согласование

Обновляйте документы после завершения работы, перед слиянием feature-ветки, при передаче проекта или подготовке релиза. На промежуточных шагах собирайте краткие заметки и готовьте одно итоговое обновление.

В конце сеанса покажите список существующих документов и предлагаемые изменения, затем запросите разрешение на перезапись. Применяйте их только после ответа пользователя. Подробный порядок находится в [Documentation Update Policy](contributor-guide.md#documentation-update-policy).

Не меняйте корневой `AGENTS.md` без нового явного разрешения. Не назначайте версию, не публикуйте выпуск и не отмечайте проверки выполненными без фактического основания.
