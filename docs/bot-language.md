# Язык программирования ботов

## Первая программа

```text
resource = nearestResource()
if resource:
    moveTo(resource)
    collect()
else:
    if random() < 0.05:
        moveTo(random() * 1600, random() * 900)

if canSpawn():
    spawn()
```

Это экономический пример. Готовый пример с боем находится в `server/scripting/example.js` и доступен кнопкой «Пример».

Язык поддерживает числовые выражения, переменные, `if/else` с отступами из пробелов, комментарии `#`, `true/false/null`, `and/or/not`, `+ - * / %`, сравнения `== != < <= > >=`. Переменные создаются заново на каждом тике. Строк, циклов, массивов, доступа к свойствам объектов и произвольного JavaScript нет.

| Bot API | Результат / действие |
| --- | --- |
| `nearestEnemy()`, `nearestResource()`, `nearestFriendly()` | Ближайшая видимая цель или `null`; радиус 250 |
| `moveTo(target)`, `moveTo(x, y)` | Задать цель движения; координаты ограничены картой |
| `attack(target)` | Удар по противнику в радиусе 35 с перезарядкой 500 мс |
| `collect()` | Собрать до 2 единиц ресурса в радиусе 25 за тик |
| `canSpawn()` | Можно ли создать нового бота |
| `spawn()` | Создать бота у своей базы за 30 ресурсов |
| `distance(target)` | Расстояние до цели |
| `random()` | Случайное число от 0 включительно до 1 исключительно |
| `getHealth()`, `getResources()` | HP бота и общий запас ресурсов игрока |
| `getPosition()`, `getBase()` | Текущая позиция и своя база (либо `null`) |

Команды действий возвращают `null`. Проверяйте цель перед её использованием: `if enemy:`. За тик выполняется до 100 операций на бота; тяжёлые запросы поиска стоят дороже. При исчерпании бюджета уже подготовленные действия выполняются, а программа запускается с начала на следующем тике. При ошибке исполнения действия данного бота за этот тик отменяются, его движение прекращается; остальные игроки продолжают играть. Синтаксически неверная новая программа не заменяет действующую.

Ограничения: 8000 символов, 200 строк, 24 уровня вложенности; до 8 игроков и 40 ботов на игрока. Основные игровые параметры собраны в `server/game/config.js`.
