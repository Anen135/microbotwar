# Проверка проекта

## Проверки

```powershell
npm --prefix server test
npm --prefix frontend/client run lint
npm --prefix frontend/client run build
npm --prefix server run test:browser
```

28 тестов `node:test` проверяют движение, экономику, бой, полные матчи AI и DSL, интерпретатор, ограничения, комнаты, права хоста, изоляцию и очистку. Браузерная проверка использует два отдельных контекста Playwright: лобби, одинаковое изображение Canvas, Apply, переход к строке ошибки, различение черновика и применённой версии, вёрстку при 1024/1280/1440, появление и исчезновение подсветки попадания, победу в бою, перезапуск и выход. Для ускорения финала она прокручивает настоящие тики симуляции без ожидания реального времени. В тесте выбран одинаковый режим Canvas для точного сравнения пикселей между окнами.

По умолчанию браузерная проверка использует установленный Microsoft Edge в headless-режиме. На машине без Edge:

```powershell
cd server
npx playwright install chromium
$env:BROWSER_CHANNEL = 'chromium'
npm run test:browser
```

Также проверяются прямые адреса и перезагрузка страниц руководства и справочника, история браузера, сохранение комнаты и черновика при навигации, переключатель ЭЛТ и подсказки с мышью и клавиатурой.

Скриншоты сохраняются в `artifacts/`: `redesign-welcome.png`, `redesign-arena.png`, `how-to-play.png`, `reference.png`, `match.png`, `victory.png` и `layout-{1024,1280,1440}.png` (игнорируются Git). Старую демонстрацию движения первого этапа можно запустить через `npm --prefix server run demo`.

## Проверка изменений

Тесты сервера лежат рядом с модулями в `*.test.js`; используется встроенный `node:test`. Численный порог покрытия не установлен. Добавляйте проверки поведения и отказов, а не копию реализации. Браузерный тест запускает свой сервер на свободном порту и закрывает его после завершения.

Для документации проверьте относительные ссылки и команды по пакетным скриптам. Для клиента выполняйте lint/build; для навигации и игрового интерфейса — также браузерный сценарий. Для сервера и DSL запускайте серверные тесты.
