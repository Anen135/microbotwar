Дата подготовки: 6 октября 2026 года. Первый релиз MVP публикуется в приватном GitHub-репозитории [Anen135/microbotwar](https://github.com/Anen135/microbotwar). ## Поставка

GitHub Release содержит `microbots-arena-v1.0.0.zip` и `SHA256SUMS.txt`. Архив включает отслеживаемые исходники, lock-файлы, документацию и собранный `frontend/client/dist`. Зависимости, секреты, Git metadata и скриншоты в архив не входят.

Для готового архива достаточно `npm --prefix server ci --omit=dev` и `npm --prefix server start`. Сервис по умолчанию слушает `127.0.0.1:3001`; `HOST` и `PORT` задаются окружением. Сборка клиента нужна только для разработки или изменения frontend.
