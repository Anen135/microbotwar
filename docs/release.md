## Поставка

В поставку входят серверный код и lock-файл, документация, собранный `frontend/client/dist`. Сборка клиента требует devDependencies; работающий сервер — зависимостей из `server/package.json`. `node_modules`, скриншоты, секреты и локальные логи в Git не входят.

Сервис по умолчанию слушает `127.0.0.1:3001`. `HOST` и `PORT` задаются окружением. Для выбранной площадки настройте запуск процесса и передачу Socket.IO-трафика. Границы реализованного MVP описаны в [обзоре](overview.md).

## Запись проверки кандидата

| Поле | Значение |
| --- | --- |
| Версия и дата | Не назначены |
| Проверенный commit | Заполнить после фиксации кандидата |
| Node.js, ОС, браузер | Заполнить при проверке |
| Установка из lock-файлов | Не проверена для релизного кандидата |
| Тесты, lint, build, браузер | Заполнить после прогона |
| Целевое окружение | Не выбрано |
| Известные ограничения | [Обзор MVP](overview.md) |

Исторические результаты реализации находятся в [передаче](agents/handoff.md); они не заменяют проверку конкретного кандидата.

## Откат

Сохраните предыдущий проверенный commit и его сборку. Для отката разверните этот код, установите зависимости из его lock-файлов и восстановите сборку клиента, затем проверьте `/health` и вход двух клиентов. Перезапуск сервера удаляет активные комнаты: восстановление матчей не поддерживается.
