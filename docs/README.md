## ИИ-агентам

[Каталог agents](agents/README.md) содержит актуальные инструкции и документ передачи проекта. Технические сведения находятся в общих документах; в `agents/` фиксируются порядок работы и состояние задач.

## Обновление документов

Документация обновляется на контрольных этапах: после завершения задачи, перед слиянием feature-ветки, при передаче работы и подготовке релиза. Перезапись существующих документов требует разрешения пользователя в конце сеанса ИИ-агента. Порядок подготовки и согласования описан в [инструкциях](agents/contributor-guide.md#documentation-update-policy).

Команды выполняются из корня проекта, если не указано иначе. Источники точных значений — `server/game/config.js`, определения Bot API и пакетные скрипты.
