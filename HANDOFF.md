## Выполненные задачи интерфейса

- Итерация дизайна в `feature/arena-redesign`: матовая графитовая основа, металлические панели, акриловая накладка и золотой акцент. На арене включён отключаемый ЭЛТ-фильтр без мерцания.
- Руководство и справочник доступны отдельными страницами (`/how-to-play`, `/reference`). Навигация и история браузера сохраняют подключение и черновик; прямые адреса обслуживаются Express. До матча параметры справочника загружаются из `/api/config`.
- Пояснения убраны с игрового экрана в справочник и hover tips. Подсказки доступны с клавиатуры, закрываются по Escape и допускают наведение на сам текст.

- Ошибки компиляции и исполнения показываются рядом с редактором. Номер строки выделен отдельно; «Перейти к строке» фокусирует textarea, выделяет строку и прокручивает её в видимую область.
- Ошибки привязаны к версии исходного текста. Для изменённого черновика не предлагается переход к строке другой программы. Подтверждение Apply сохраняет именно отправленный текст, даже если пользователь успел изменить редактор.
- Исправлены русские формы количеств ботов и ресурсов. Справочник берёт игровые значения из `state.config` во время матча.
- Проверены окна 1024, 1280 и 1440 пикселей, отдельные страницы справки и длинная ошибка: колонки не перекрываются, кнопки помещаются, горизонтального переполнения страницы нет, Canvas сохраняет пропорции.
- При снижении HP сущность получает белый контур на 200 мс. Эффект гаснет и при остановленных тиках; записи исчезнувших сущностей удаляются, restart очищает прежнюю историю. Игровая логика остаётся на сервере.

## Проверки

Из корня проекта:

```powershell
npm --prefix server test
npm --prefix frontend/client run lint
npm --prefix frontend/client run build
npm --prefix server run test:browser
```

Результат: 28 серверных тестов, lint, production build и браузерный сценарий проходят. Ошибок браузера нет. Для проверки эффекта браузерный сценарий выполняет настоящий удар через симуляцию и проверяет белый пиксель контура, затем его исчезновение. Точное сравнение изображений выполняется после эффекта; в тестовых контекстах выбран одинаковый режим Canvas, чтобы чтение пикселей не переключало только одно окно между GPU и CPU.

## Границы MVP

- Сохранён существующий React/Vite-каркас; textarea вместо Monaco, небольшой DSL вместо JavaScript.
- 10 тиков/с; до 8 игроков и 40 ботов на игрока; бюджет 100 операций/тик/бот.
- До Apply работает встроенный AI. Режим и программа сохраняются при restart.
- Потеря соединения означает поражение. Повторного входа в начавшийся матч нет; для новой игры после ухода остальных создаётся новая комната.
- Состояние только в памяти, без аккаунтов, БД и деплоя. Мобильная версия и публичная нагрузка не входили в задачу.
- `AGENTS.md` сохранён без изменений по исходной инструкции пользователя; его историческое описание scaffold устарело, актуальное состояние отражено в README.
