## Оставшаяся работа: этап 8, небольшие отдельные изменения

### 1. Сделать ошибки в редакторе удобнее

Файл: `frontend/client/src/components/editor.jsx`; при необходимости передать ошибку компиляции из `App.jsx`.

Сервер возвращает ошибки в формате `Line N: ...`. Показывать номер строки отдельно и добавить действие «Перейти к строке»: фокус textarea и выделение соответствующей строки через `setSelectionRange`. Не менять parser/AST и не подключать Monaco. Для ошибок без номера строки оставить обычное сообщение.

Приёмка: программа `x = 1` / `y = missing` сообщает строку 2; переход выделяет только вторую строку. Ошибка компиляции `attak(null)` тоже доступна рядом с редактором. Остальная игра продолжает работать.

### 2. Довести тексты и desktop-layout

Файлы: `App.jsx`, `App.css`, `index.css`, `components/editor.jsx`.

Исправить русские формы количеств («1 бот», «2 бота», «5 ботов»; аналогично ресурсы). Проверить ширины 1024, 1280 и 1440: кнопки доступны, справка читабельна, Canvas сохраняет пропорции. Подсказки о размерах карты, стоимости и радиусах брать из переданной `state.config`, чтобы они не расходились с серверной конфигурацией. Мобильная версия не входит в MVP.

Приёмка: понятные тексты, нет перекрытий; открытая справка и длинная ошибка не ломают две колонки. Не менять игровую механику.

### 3. Добавить простой визуальный отклик боя

Файл: `components/renderer.jsx`.

Сравнивать HP сущности с предыдущим снимком в `useRef`. На уменьшение HP коротко выделять сущность светлым контуром (примерно 200 мс). Очистить историю для исчезнувших ID и при restart. Всё вычислять только для изображения; не добавлять урон или игровые решения на клиент. Не добавлять сетевые события, библиотеки эффектов и интерполяцию.

Приёмка: во время настоящего боя попадания заметны, а итоговый HP по-прежнему приходит с сервера. После перезапуска не остаются контуры старых ботов.

## Зафиксированные решения

- Сохранён существующий React/Vite-каркас; никаких новых UI-фреймворков.
- Простой textarea вместо Monaco, Python-подобный DSL вместо JavaScript.
- 10 тиков/с; 8 игроков; 40 ботов на игрока; операции DSL ограничены 100/тик/бот.
- Игроки начинают со встроенным AI; «Применить» включает программу. Режим и код сохраняются при restart.
- Отключение означает поражение; восстановления сессии и входа в начатый матч нет. Хост передаётся следующему участнику, пустая комната удаляется.
- Комнаты в памяти, без БД, аккаунтов и деплоя. Порт 3001; Vite proxy настроен на него.
- В этой копии нет Git metadata, поэтому коммиты/PR не созданы.
